Este repositório contém os dados complementares do artigo submetido ao COBICET.

## 📁 Estrutura do Repositório

Dentro da pasta `projetos/`, você encontrará os seguintes arquivos fundamentais para a reprodutibilidade desta pesquisa:

* **PROMPT.txt**: O comando (prompt) exato enviado à IA para orientar a classificação das questões.
* **Exemplo de saída gerado pelo programa em CSV.txt**: Saída gerada pelo modelo Gemini em CSV.
